## 2. Ringkasan Dasar Teori

Perancangan basis data fisik merupakan tahap translasi akhir dari model konseptual dan logis ke dalam implementasi sistem manajemen basis data relasional (*RDBMS*) yang sebenarnya. Pada tahap ini, seluruh entitas didefinisikan ke dalam bentuk tabel fisik, kolom, tipe data, serta batasan (*constraints*) integritas.

Penerapan *Foreign Key* dengan aksi referensial seperti `ON DELETE CASCADE` dan `ON UPDATE CASCADE` sangat penting untuk memastikan bahwa perubahan atau penghapusan data pada tabel induk (*parent*) secara otomatis disinkronkan ke tabel anak (*child*), sehingga mencegah terjadinya *orphan record* (data yatim yang tidak berelasi). Selain itu, hubungan *Many-to-Many* ($M:N$) antar entitas wajib diselesaikan menggunakan tabel perantara (*junction table*) yang memiliki *Composite Primary Key*.

### Spesifikasi Entitas & Relasi Fisik:
Basis data fisik yang dibangun dinamakan `db_akademik_25430092` yang terdiri dari 6 tabel utama:

6. **`detail_krs`**: Tabel perantara (*junction table*) berelasi *Many-to-Many* yang menghubungkan `krs` dan `jadwal_kuliah` untuk memuat rincian nilai akhir mahasiswa.

**Script SQL DDL Lengkap:**
```sql
-- =====================================================================
-- NAMA PRAKTIKUM : MODUL 3 - PERANCANGAN BASIS DATA FISIK
-- NIM            : 25430092
-- DATABASE       : db_akademik_25430092
-- =====================================================================

CREATE DATABASE IF NOT EXISTS db_akademik_25430092;
USE db_akademik_25430092;

-- 1. Tabel Mahasiswa
CREATE TABLE mahasiswa (
    id_mahasiswa INT AUTO_INCREMENT PRIMARY KEY,
    nim_mahasiswa CHAR(10) UNIQUE NOT NULL,
    nama_mahasiswa VARCHAR(100) NOT NULL,
    prodi_mahasiswa VARCHAR(50) NOT NULL,
    no_hp_mahasiswa VARCHAR(15),
    status_mahasiswa ENUM('Aktif', 'Cuti', 'Lulus', 'Drop Out') DEFAULT 'Aktif'
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 2. Tabel Dosen
CREATE TABLE dosen (
    id_dosen INT AUTO_INCREMENT PRIMARY KEY,
    nidn_dosen CHAR(10) UNIQUE NOT NULL,
    nama_dosen VARCHAR(100) NOT NULL,
    telepon_dosen VARCHAR(15)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 3. Tabel Mata Kuliah
CREATE TABLE mata_kuliah (
    id_matkul INT AUTO_INCREMENT PRIMARY KEY,
    kode_matkul VARCHAR(10) UNIQUE NOT NULL,
    nama_matkul VARCHAR(100) NOT NULL,
    sks_matkul TINYINT NOT NULL,
    semester_matkul TINYINT NOT NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 4. Tabel Jadwal Kuliah
CREATE TABLE jadwal_kuliah (
    id_jadwal INT AUTO_INCREMENT PRIMARY KEY,
    id_matkul INT NOT NULL,
    id_dosen INT NOT NULL,
    hari_kuliah VARCHAR(10) NOT NULL,
    jam_kuliah TIME NOT NULL,
    ruang_kuliah VARCHAR(20) NOT NULL,
    CONSTRAINT fk_jadwal_matkul FOREIGN KEY (id_matkul) REFERENCES mata_kuliah(id_matkul) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT fk_jadwal_dosen FOREIGN KEY (id_dosen) REFERENCES dosen(id_dosen) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 5. Tabel KRS
CREATE TABLE krs (
    id_krs INT AUTO_INCREMENT PRIMARY KEY,
    no_krs CHAR(15) UNIQUE NOT NULL,
    tgl_krs DATE NOT NULL,
    id_mahasiswa INT NOT NULL,
    tahun_akademik VARCHAR(9) NOT NULL,
    CONSTRAINT fk_krs_mahasiswa FOREIGN KEY (id_mahasiswa) REFERENCES mahasiswa(id_mahasiswa) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 6. Tabel Detail KRS (Junction Table)
CREATE TABLE detail_krs (
    id_krs INT NOT NULL,
    id_jadwal INT NOT NULL,
    nilai_huruf ENUM('A', 'B+', 'B', 'C+', 'C', 'D', 'E') NULL,
    nilai_angka DECIMAL(3,2) NULL,
    PRIMARY KEY (id_krs, id_jadwal),
    CONSTRAINT fk_detail_krs FOREIGN KEY (id_krs) REFERENCES krs(id_krs) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT fk_detail_jadwal FOREIGN KEY (id_jadwal) REFERENCES jadwal_kuliah(id_jadwal) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
