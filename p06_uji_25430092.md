# Skenario Uji Basis Data Akademik (Modul 6)

| Kode Uji | Jenis Uji | Masukan / Perintah SQL | Harapan Sistem | Hasil Nyata | Status |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **UJ-01** | Positif | INSERT data mahasiswa baru yang valid | Berhasil disimpan ke tabel | Query OK, 1 row affected | **LULUS** |
| **UJ-02** | Positif | INSERT data dosen baru yang valid | Berhasil disimpan ke tabel | Query OK, 1 row affected | **LULUS** |
| **UJ-03** | Positif | INSERT data mata kuliah baru yang valid | Berhasil disimpan ke tabel | Query OK, 1 row affected | **LULUS** |
| **UJ-04** | Negatif | INSERT mahasiswa dengan NIM kembar | Ditolak oleh *Unique Key* | ERROR 1062: Duplicate entry | **LULUS** |
| **UJ-05** | Negatif | INSERT SKS mata kuliah bernilai negatif (`-3`) | Ditolak oleh *Check Constraint* | ERROR 4025: Check constraint failed | **LULUS** |
| **UJ-06** | Negatif | INSERT KRS dengan ID Mahasiswa yang tidak terdaftar | Ditolak oleh *Foreign Key* | ERROR 1452: Cannot add or update a child row | **LULUS** |
| **UJ-07** | Positif | UPDATE nama mahasiswa berdasarkan NIM | Berhasil mengubah data | Query OK, 1 row affected | **LULUS** |
| **UJ-08** | Negatif | UPDATE data tanpa klausa WHERE di mode aman | Ditolak oleh *Safe Update Mode* | ERROR 1175: You are using safe update mode | **LULUS** |
| **UJ-09** | Positif | DELETE data mahasiswa uji coba | Berhasil menghapus data | Query OK, 1 row affected | **LULUS** |
